# ADR-011: Structured Workday Review-gate issues

**Status:** Accepted
**Date:** 2026-05-08

## Context

The Workday Review step (final-page validation) was reported in free-form
text: "experience missing", "title mismatch", etc. Two problems:

- A downstream auto-submit gate needs to reason about *what* is wrong,
  not just *that* the page has issues. Free-form strings force string
  matching, which is brittle.
- The user-facing review artifact (`apply-review.md`) and the structured
  state in `apply-review.json` drifted, because each was generated by a
  different code path.

There was also no upper bound on step transitions; a stuck Workday flow
could loop indefinitely without surfacing *which* field stalled it.

## Decision

- Define a `ReviewIssue` data class (in `services/workday/review_gate.py`)
  with `code`, `message`, `details` fields. Codes are constants:
  - `WD_REVIEW_EXPERIENCE_MISSING`
  - `WD_REVIEW_TITLE_MISMATCH`
  - `WD_REVIEW_DATE_MISMATCH`
  - `WD_REVIEW_ROLE_DESCRIPTION_MISSING`
  - `WD_REVIEW_GPA_MISMATCH`
  - `WD_REVIEW_LINKEDIN_INVALID`
  - `WD_REVIEW_DUPLICATE_UPLOAD`
- `apply-review.json::validation_issues[]` is the canonical form;
  `apply-review.md` is rendered from it via `review_validation_messages`.
- Auto-submit reads `validation_issues == [] AND required_empty == []`
  as a gate (see ADR-012 for the rest of the auto-submit chain).
- Introduce named constants for orchestration limits:
  - `_WORKDAY_MAX_STEPS = 8`
  - `_WORKDAY_STEP_CHANGE_TIMEOUT_MS = 25000`
- When a step is stuck (`prev_step == step`), `_required_empty_fields`
  is queried once and added to `skipped` so the operator sees which
  field stalled progress.

## Consequences

- Auto-submit can be gated on structured state without parsing prose.
- The user-facing review artifact stays in sync with the gate because
  both render from the same `validation_issues` list.
- Adding a new validation rule = adding a new `ISSUE_*` constant +
  detector; downstream consumers automatically pick it up.
- Named timeout / step constants make tuning a single-line edit and
  prevent magic numbers from sprouting across the file.
- The `skipped` payload becomes a real diagnostic. When a flow stalls,
  the artifact tells the operator which Required field caused it
  instead of leaving them to guess.
